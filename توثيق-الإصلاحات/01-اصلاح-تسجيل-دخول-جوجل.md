# إصلاح تسجيل الدخول بجوجل (Error 400: redirect_uri_mismatch)

## المشكلة
عند محاولة تسجيل الدخول بجوجل من دومين الإنتاج (`https://sadim.cloud`)، جوجل يرفض بخطأ:
```
Error 400: redirect_uri_mismatch
```

## السبب
رابط الـ callback يُبنى ديناميكياً في الكود:
```python
redirect_uri = url_for('loading_bp.google_auth_callback', _external=True)
```
هذا يعتمد على `request.scheme` — أي البروتوكول اللي فلاسك "يشوف" إنه استقبل الطلب فيه. في الإعداد النموذجي (Nginx يفك تشفير HTTPS ثم يمرر الطلب لـ gunicorn عبر HTTP عادي بالداخل)، فلاسك ما يعرف إن الطلب الأصلي كان HTTPS **إلا** لو فيه middleware يقرأ هيدر `X-Forwarded-Proto`.

هذا الـ middleware (`ProxyFix`) كان موجود بالكود لكن **معطّل** (سطر معلّق) في `run.py`. النتيجة: فلاسك يبني الرابط كـ `http://sadim.cloud/auth/google/callback` بدل `https://` — وهذا غير مطابق لما هو مسجّل بـ Google Cloud Console (`https://sadim.cloud/auth/google/callback` فقط)، فيرفضه جوجل.

تم التأكد من هذا عبر مراجعة الروابط المسجّلة فعلياً بـ Google Cloud Console (Credentials → OAuth Client) — كانت صحيحة ومطابقة للدومين، مما استبعد احتمال خطأ في الإعداد على جوجل نفسه.

## الحل
نقل تفعيل `ProxyFix` من `run.py` (كان معطّلاً وغير مضمون إنه ينفّذ حسب طريقة تشغيل gunicorn) إلى `app/__init__.py` مباشرة بعد إنشاء كائن `app`، حتى يشتغل بغض النظر عن نقطة الدخول المستخدمة بالإنتاج:

```python
# app/__init__.py
from werkzeug.middleware.proxy_fix import ProxyFix
...
app = Flask(__name__)
app.config.from_object('app.config.settings')
app.wsgi_app = ProxyFix(app.wsgi_app, x_for=1, x_proto=1, x_host=1)
```

وشيل الاستدعاء المكرر/المعطّل من `run.py`.

## شرط للتشغيل الصحيح بالإنتاج
هذا الحل يعتمد على إن **Nginx يرسل فعلاً** هيدر `X-Forwarded-Proto`. لازم يكون بإعداد Nginx (داخل الـ `location`/`server` block اللي يعمل `proxy_pass` للتطبيق):
```nginx
proxy_set_header X-Forwarded-Proto $scheme;
proxy_set_header X-Forwarded-Host $host;
proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
```
لو هالهيدرز مو موجودة بإعداد Nginx الحالي، لازم تُضاف وإلا المشكلة بتستمر.
