## ملاحظات مهمة قبل النشر بالإنتاج

- الإصلاح رقم 4 يحل مشكلة تشغيل نفس البوت مرتين **عند بدء التشغيل فقط**. لو تستخدم أكثر من worker واحد بـ gunicorn، لسا فيه قيد: عمليات "تشغيل/إيقاف/حذف بوت" اللي يسويها المستخدم من لوحة التحكم تعتمد على إن نفس الـ worker يتعامل مع كل طلبات ذاك البوت. التفاصيل والتوصية موجودة بالملف رقم 4.
- الملف رقم 11 يحتاج تشغيل `create_tables()` يدوياً بعد النشر (عمود `posts.image_path` الجديد) وتثبيت `Pillow` (أُضيفت لـ requirements.txt).
- نطاق الدفع (PayPal) ونظام الإحالة المرتبط فيه (فتح ميزات مقابل دعوة 5 أشخاص) **مؤجّلان بالكامل** لجلسة لاحقة بطلب صريح — ما تم تنفيذ أي منهما.
